# Triage labels

Five canonical triage roles:

- `needs-triage`: Issue mới, chưa có ai phân tích
- `needs-info`: Cần thêm thông tin từ reporter hoặc liên quan
- `ready-for-agent`: Sẵn sàng để agent làm việc trên issue
- `ready-for-human`: Sẵn sàng để con người (dev/lead) xem xét
- `wontfix`: Không sẽ sửa được issue này

Mỗi label string bằng chính tên role (không có prefix).
